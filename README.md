# chat-app
シンプルなチャットアプリケーション

- チャットグループの作成
- メッセージの送受信
- メッセージの情報のエクスポート・インポート
- メールアドレスによる認証

# 目的
フルスタック(フロントエンド・バックエンド・データベース)開発をすることで、幅広い技術の知識を得る。

Docker・Github Flow・WebRTC・JWT・Axum・Solid.js・認証のデファクトスタンダード・クロスプラットフォーム開発・DB設計・SQLなど

# 使用技術

### 全般
- git
- Docker

### バックエンド
- Rust
- Axum
- Shuttle

### フロントエンド
- Solid.js
- Tauri
- Rust

### データベース
- MySQL
